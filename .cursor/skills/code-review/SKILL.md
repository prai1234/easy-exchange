# Easy Book Exchange Code Review

1. Read the relevant specification.
2. Compare the code to the acceptance criteria.
3. Check validation and error handling.
4. Check naming and organization.
5. Check for unnecessary complexity.
6. Check for obvious regressions.
7. Report problems before changing code.
8. Recommend the smallest appropriate correction.
