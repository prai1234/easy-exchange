# Easy Book Exchange Feature Planner

Use this skill before implementing a new feature.

## Workflow
1. Read the relevant files in `/specs`.
2. Identify the user story and functional requirement.
3. Identify frontend changes.
4. Identify backend changes.
5. Identify database changes.
6. Identify validation requirements.
7. Identify edge cases.
8. Define acceptance criteria.
9. Produce a small implementation checklist.
10. Do not begin implementation until the plan is complete.

Prefer simple solutions appropriate for a student project.
