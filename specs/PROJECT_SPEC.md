# Easy Book Exchange Project Specification

## Purpose
Easy Book Exchange is a small community web application for exchanging physical books.

## Primary Goal
Provide a simple, understandable workflow for listing books and requesting exchanges.

## Scope
The MVP includes book listings, search, genre filtering, listing management, exchange requests, and status tracking.

## Non-Goals
- Payments
- Shipping
- Real-time chat
- OAuth/social login
- Recommendation engine
- Native mobile application

## Definition of Done
The application is complete when users can:
1. View all books.
2. Add a book.
3. Search and filter books.
4. View book details.
5. Edit and delete listings.
6. Submit an exchange request.
7. See statuses of Available, Pending, or Exchanged.
