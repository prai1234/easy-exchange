# Easy Book Exchange Requirements

## Functional Requirements

### FR-01 View Books
The application shall display book listings from the database.

### FR-02 Add Book
The application shall allow a user to create a listing with title, author, genre, condition, description, owner name, and owner email.

### FR-03 Search Books
The application shall allow searching by title or author.

### FR-04 Filter Books
The application shall allow filtering by genre.

### FR-05 Book Details
The application shall provide a detailed view for a selected book.

### FR-06 Exchange Request
The application shall allow a visitor to request an exchange for an Available book.

### FR-07 Exchange Status
Each book shall have one status: Available, Pending, or Exchanged.

### FR-08 Edit Listing
The application shall allow an existing listing to be edited.

### FR-09 Delete Listing
The application shall allow an existing listing to be deleted.

## Nonfunctional Requirements

### NFR-01 Usability
The interface should be understandable without separate instructions.

### NFR-02 Responsive Design
The layout should work on desktop and smaller screens.

### NFR-03 Validation
Required fields must be validated on the client and server.

### NFR-04 Error Handling
Errors must produce understandable messages.

### NFR-05 Maintainability
Frontend, backend, and database responsibilities must remain separated.
