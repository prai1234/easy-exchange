# UI Specification

## Main Catalog
- Header with application name
- Intro/hero message
- Search field
- Genre filter
- Add Book button
- Book card grid

## Book Card
- Title
- Author
- Genre
- Condition
- Status badge
- View Details button

## Add/Edit Book Form
Fields:
- Title
- Author
- Genre
- Condition
- Description
- Owner name
- Owner email

## Book Details
- Full listing information
- Exchange request form when status is Available
- Edit button
- Delete button

## Exchange Request Form
Fields:
- Requester name
- Requester email
- Offered book
- Message

## States
- Loading
- Empty catalog
- Validation error
- API error
- Success
